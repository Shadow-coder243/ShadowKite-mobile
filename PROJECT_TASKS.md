# ShadowKite — Liste de tâches du projet

> Cette liste constitue le backlog initial de ShadowKite. Les cases sont volontairement laissées décochées : aucune tâche fonctionnelle n’est considérée comme terminée par l’initialisation des dépôts.

## Règles de suivi

- [ ] Une tâche est cochée uniquement lorsqu’un livrable vérifiable existe.
- [ ] Toute modification importante doit être reliée à une issue ou à un pull request.
- [ ] Les tâches Produit et Design précèdent les tâches de développement dépendantes.
- [ ] Les éléments non indispensables au MVP restent après la mise en ligne d’une première version testable.

## Définition du MVP

Le MVP sera considéré comme atteint lorsqu’une personne pourra créer un compte, compléter son profil, saisir les informations essentielles de son CV, télécharger un CV PDF, ajouter un projet, publier un portfolio et partager un lien public consultable sur téléphone.

L’application mobile native, les modèles supplémentaires, le domaine personnalisé, les statistiques avancées, l’import de CV, le QR code et les fonctions multilingues restent hors du premier MVP, sauf décision contraire documentée dans une issue.
